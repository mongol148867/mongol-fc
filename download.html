# Простой файлообменник для Railway ## Локальный запуск ```bash python -m venv .venv # Windows: .venv\Scripts\activate # macOS/Linux: source .venv/bin/activate pip install -r requirements.txt python app.py ``` Откройте http://localhost:5000. ## Деплой на Railway 1. Загрузите содержимое этой папки в GitHub. 2. В Railway создайте проект из этого GitHub-репозитория. 3. В сервисе Railway откройте **Volumes** и создайте Volume с mount path `/data`. 4. В **Variables** добавьте `DATA_DIR=/data`. 5. После деплоя откройте выданный Railway домен. Опционально задайте `MAX_UPLOAD_MB=250` (или другое значение) в Variables. ## Важно - Без подключённого Volume файлы и база могут исчезнуть при redeploy/restart. - Коды состоят из пяти символов (латинские буквы в верхнем и нижнем регистре и цифры), поэтому ссылку всё ещё можно подобрать. Не используйте сервис для секретных или чувствительных файлов. - Это простой стартовый проект: нет авторизации, квот, срока хранения или автоматического удаления файлов. - Для публичного сервиса стоит добавить защиту от злоупотреблений, лимиты хранения и очистку старых файлов.
